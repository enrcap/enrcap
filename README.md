## Proyectos destacados

### [Predicción del abandono y rendimiento académico](https://github.com/enrcap/student-academic-performance)

Estudio datos de **4.424 estudiantes** para clasificar su situación académica, estimar notas y explorar perfiles. Incluye implementaciones propias de kNN, regresión logística y regresión lineal, comparadas con modelos de referencia mediante validación cruzada.

**Qué demuestra:** preparación de datos, implementación de modelos, evaluación y análisis de resultados.  
**Herramientas:** Python, NumPy, pandas, scikit-learn y Jupyter.

### [Análisis de reseñas con tres modelos de bases de datos](https://github.com/enrcap/amazon-reviews-databases)

Sistema para cargar y analizar reseñas de Amazon combinando almacenamiento relacional, documentos y grafos. Incluye consultas analíticas, visualizaciones y recomendaciones de productos basadas en popularidad.

**Qué demuestra:** modelado de datos, integración de bases de datos y consultas sobre relaciones entre usuarios y productos.  
**Herramientas:** Python, SQL, MySQL, MongoDB, Neo4j y Cypher.

### [Planificador de rutas de Madrid](https://github.com/enrcap/madrid-route-planner)

Calcula y compara recorridos por distancia, tiempo estimado y espera en semáforos sobre una red de calles de OpenStreetMap. Utiliza una implementación propia de Dijkstra y representa las rutas sobre el mapa.

**Qué demuestra:** teoría de grafos, diseño de algoritmos, tratamiento de datos geográficos y comprobación de resultados frente a NetworkX.  
**Herramientas:** Python, pandas, NetworkX, Matplotlib y GitHub Actions.

### [Buscando al Coronel Kurtz: agentes de inteligencia artificial](https://github.com/enrcap/kurtz-ai-agents)

Simulación en consola donde los agentes exploran un palacio con peligros ocultos y planifican el cruce de un río con corrientes. Permite observar cómo cambia su conocimiento y cómo eligen sus acciones.

**Qué demuestra:** razonamiento lógico, búsqueda BFS, inferencia bayesiana, planificación con A* y resolución de un MDP mediante Value Iteration.  
**Herramientas:** Python y NumPy.
